Quickly share your [Kalo](https://github.com/malingib/kalo) meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the [Kalo](https://github.com/malingib/kalo) from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer [Kalo](https://github.com/malingib/kalo) Settings, and then you can add the API Key by opening up the [Kalo](https://github.com/malingib/kalo) App in Raycast.
